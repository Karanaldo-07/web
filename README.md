# InterviewLens

A mobile-first interview preparation website. Enter a job title or job description and get a practical preparation pack: common questions, technical questions, behavioral questions, things to prepare, and community-verified interview questions.

## MVP
Frontend-only starter using browser local storage for the community confirmation prototype. Backend/search integration can be added next.

## Product principle
Generated questions are clearly labeled as generated/recommended. A question gets a **Reported Asked** signal only after users confirm they were actually asked it.
